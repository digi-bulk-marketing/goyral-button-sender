# Goyral Button Sender

Goyral Button Sender by hpwebmart.com.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/goyral-button-sender/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Goyral Button Sender** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/goyral-button-sender/releases/latest) and reinstall.
